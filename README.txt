AdamIs CRM Solutions — Standalone website

To open locally:
1. Keep index.html, style.css, main.js, and the images folder together.
2. Double-click index.html to open it in your browser.
3. An internet connection is needed for Google Fonts and externally hosted photography.

This is a front-end demonstration. Contact form submissions are stored only in this browser; patient portal and payments are demo-only. Do not enter real patient information.

For GitHub Pages, upload these files to the repository root. No npm or Node.js is required for this standalone version.
